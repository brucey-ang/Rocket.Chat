# Rocket.Chat项目说明文档

## 1. 项目概述

Rocket.Chat是一个开源的团队通信平台，基于Meteor框架构建，使用TypeScript开发。它提供了安全、可定制的通信解决方案，适用于对数据保护有高标准要求的组织。

### 主要特性
- **实时聊天**：支持一对一聊天、群组聊天和频道
- **文件共享**：支持在聊天中发送和接收文件
- **视频和音频通话**：集成WebRTC支持音视频通信
- **移动应用**：提供iOS和Android客户端
- **插件系统**：通过Apps Engine扩展功能
- **多语言支持**：国际化和本地化支持
- **企业级安全**：符合企业安全标准
- **联邦通信**：支持跨服务器通信

## 2. 技术架构

### 2.1 整体架构
Rocket.Chat采用Monorepo架构，将多个相关包组织在一个代码库中。项目支持从单体应用到微服务的多种部署模式。

### 2.2 核心技术栈
- **运行环境**：Node.js 22.16.0
- **包管理器**：Yarn 4.10.3
- **前端框架**：React
- **后端框架**：Meteor
- **数据库**：MongoDB
- **微服务框架**：Moleculer
- **UI组件库**：自研Fuselage组件库
- **插件系统**：Apps Engine

### 2.3 微服务架构
Rocket.Chat支持微服务部署模式，使用Moleculer作为服务框架：
- 服务间通信通过Broker实现
- 支持服务发现和负载均衡
- 提供服务监控和指标收集
- 支持分布式部署

## 3. 项目结构

### 3.1 根目录结构
```
Rocket.Chat/
├── apps/                    # 应用目录
│   ├── meteor/              # 主Meteor应用
│   └── uikit-playground/    # UI组件演示应用
├── packages/                # 核心包目录
├── ee/                      # 企业版功能
├── .github/                 # GitHub相关配置
├── .yarn/                   # Yarn配置
└── ...
```

### 3.2 核心包结构
项目采用模块化设计，主要包包括：
- **core-services**：核心服务接口和实现
- **models**：数据模型定义
- **apps-engine**：插件引擎
- **fuselage-ui-kit**：UI组件库
- **livechat**：在线客服功能
- **omnichannel**：全渠道客服
- **federation**：联邦通信功能

## 4. 核心组件详解

### 4.1 服务架构 (core-services)
Rocket.Chat采用服务化架构，核心服务包括：
- **Authorization**：权限认证服务
- **Apps**：插件引擎服务
- **Presence**：用户在线状态服务
- **Account**：账户管理服务
- **Room**：房间管理服务
- **Message**：消息服务
- **User**：用户服务
- **Team**：团队服务
- **Media**：媒体服务
- **Voip**：语音通话服务

### 4.2 数据模型 (models)
数据模型基于MongoDB设计，主要模型包括：
- **Users**：用户模型
- **Rooms**：房间模型
- **Messages**：消息模型
- **Subscriptions**：订阅模型
- **Settings**：设置模型
- **Integrations**：集成模型
- **Livechat**：在线客服相关模型

### 4.3 插件系统 (apps-engine)
Rocket.Chat提供强大的插件系统，允许开发者扩展平台功能：
- 监听消息和房间事件
- 发送消息给用户和访客
- 注册新的斜杠命令
- 注册新的HTTP端点
- 使用键值存储系统
- 应用特定设置

### 4.4 UI组件库 (fuselage)
Rocket.Chat使用自研的Fuselage UI组件库：
- 基于React构建
- 提供丰富的UI组件
- 支持主题定制
- 响应式设计
- 可访问性支持

## 5. 联邦通信功能

### 5.1 概述
Rocket.Chat支持联邦通信，允许不同服务器之间的用户进行通信：
- **Matrix协议**：基于Matrix协议实现联邦通信
- **跨服务器通信**：支持不同Rocket.Chat实例间通信
- **安全性**：提供安全的跨服务器通信机制

### 5.2 实现方式
- 使用Matrix协议作为底层通信协议
- 通过Federation SDK实现协议转换
- 支持端到端加密
- 提供联邦房间管理

## 6. 企业版功能 (ee/)

企业版提供了额外的高级功能：
- **许可证管理**：企业版许可证系统
- **网络代理**：企业网络环境支持
- **PDF工作器**：PDF处理服务
- **媒体通话**：高级媒体通话功能
- **主题定制**：UI主题定制能力
- **存在服务**：增强的用户状态管理

## 7. 开发环境

### 7.1 环境要求
- Node.js 22.16.0
- Yarn 4.10.3
- MongoDB 4.4+
- Git

### 7.2 启动开发环境
```bash
# 安装依赖
yarn install

# 启动开发服务器
yarn dev
```

### 7.3 微服务模式
```bash
# 启动微服务模式
TRANSPORTER=TCP yarn dev
```

## 8. 部署选项

### 8.1 单体部署
- 所有服务运行在单个进程中
- 适合小型部署和开发环境
- 配置简单，易于管理

### 8.2 微服务部署
- 服务分布式运行
- 适合大型部署和高可用需求
- 支持水平扩展
- 需要额外的配置和管理

## 9. 测试体系

### 9.1 单元测试
- 使用Jest和Mocha进行单元测试
- 覆盖核心服务和组件
- 提供测试覆盖率报告

### 9.2 端到端测试
- 使用Playwright进行E2E测试
- 覆盖用户交互流程
- 支持联邦通信测试

### 9.3 API测试

- 验证接口功能和性能

## 10. 国际化支持

Rocket.Chat提供完整的国际化支持：
- 多语言界面
- 日期和时间本地化
- 数字和货币格式化
- RTL语言支持

## 总结

Rocket.Chat是一个功能丰富、架构先进的开源团队通信平台。它采用现代化的技术栈，提供了从基础聊天到企业级功能的完整解决方案。通过模块化设计和微服务架构，Rocket.Chat既适合小型团队使用，也能满足大型企业的复杂需求。其插件系统和联邦通信功能使其具有很强的扩展性和互操作性。
